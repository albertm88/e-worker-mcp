# e-worker-mcp 使用说明

> 给「人」看的操作手册，不涉及代码。你只需要会打字、会复制粘贴、会点「同意」。

---

## 一、这是什么东西？

一个装在电脑里的「打杂小助手」。

你平时烦的那些事——记待办、整理会议纪要、记工时、写日报、收拾文件夹、检查电脑环境——以前要么用脑子记，要么手动做。现在你只要**用聊天的方式吩咐 AI**，它就帮你把这些事办了，数据都存在你自己电脑上，不会上传到任何地方。

简单说：**你说人话，它干活，干之前先问你确认。**

---

## 二、它到底能帮你做什么？

| 你烦的事 | 它能做 | 举例子 |
|---------|--------|--------|
| 待办太多记不住 | 帮你记待办、改待办、查待办 | 「记个事：明天下午提交报销单」 |
| 开会记了一堆笔记 | 从会议记录里提取「要做的事」 | 「整理这段会议纪要，把要办的事列出来」 |
| 忘记今天干了啥 | 记工时、自动生成日报/周报 | 「今天写周报花了 2 小时」「生成今天的日报」 |
| 下载文件夹乱成一团 | 按规则帮你归档整理 | 「把下载目录里的 PDF 按文件类型分文件夹放好」 |
| 电脑环境出问题 | 检查环境并告诉你怎么修 | 「检查一下我的开发环境有没有问题」 |

共 24 个能力，日常用到的就是上面这些。

## 三、怎么装？（一次性，约 5 分钟）

> 如果你已经让技术人员帮你装好了，直接跳到「四、怎么用」。

### 第 1 步：确认装好运行环境

打开电脑上的终端（Windows 搜「PowerShell」），输入下面命令，能看到版本号就说明没问题：

```
python --version
```

### 第 2 步：安装

把下面 3 行命令依次复制进终端运行（每行回车一次）：

```
cd D:\git-workspace\mcp-projects\e-worker-mcp
uv venv --python 3.12
uv pip install --python .venv\Scripts\python.exe -e ".[dev]"
```

看到一堆文字滚动完、没有红色报错，就装好了。

### 第 3 步：告诉你的 AI 助手「有这个工具」

在 AI 助手的设置里找到 **MCP 服务器** 配置（不同软件叫法略有不同：Claude 叫 MCP 服务器、其他软件可能在「插件」「外部工具」里），添加一项：

- 名称：`e-worker-mcp`
- 命令：`D:\git-workspace\mcp-projects\e-worker-mcp\.venv\Scripts\python.exe`
- 参数：`-m e_worker.server`
- 工作目录：`D:\git-workspace\mcp-projects\e-worker-mcp`

保存后**重启 AI 助手**。

### 第 4 步：验证装好了没

对 AI 说一句：

> 「列出当前所有待办」

如果它回答「当前没有待办」或「0 条待办」，就说明装成功了。如果它说「没有这个工具」，说明配置没生效，检查第 3 步。

## 四、怎么用？（日常使用）

用起来就是**正常聊天**，不用学任何命令。这里给你几个照着说就行的例子：

### 记待办

> 记个待办：明天上午 10 点前提交报销单，工作类

AI 直接记录并回你「已记录 ✓」，不会反复问确认。

### 查看待办

> 看看我有哪些待办没做完

### 改待办 / 标记完成

> 把「提交报销单」改成「已做完」

### 整理会议纪要

> 把这段会议记录整理成待办：今天下午例会，小王负责跟进数据库迁移，周五前完成；需要整理测试报告

AI 会把「要办的事」列出来给你看，确认后才会记成待办。**它只提取，不会擅自帮你记**（纪要提取本身不写库，落库动作在免确认域内）。

### 记工时

> 今天下午给「数据库迁移」记 1 小时

### 生成日报

> 生成今天的日报

它会告诉你今天完成了什么（按工作/学习分开）、记了多少工时。

### 整理文件

> 把 D 盘下载文件夹里的文件按类型归档一下

**注意**：这个操作第一次会被拦截，AI 会告诉你「需要人工确认」。这是因为文件操作比较敏感，需要你先在配置文件里放行（见「五、安全是怎么回事」）。

### 检查电脑环境

> 检查一下我的开发环境

它会告诉你环境信息（Python 版本、磁盘剩余空间、端口占用等）和有没有问题，以及建议怎么修。**它只给建议，不会自动动手修。**

## 五、安全是怎么回事？（重要，看一遍就懂）

这个工具的设计原则：**AI 只能「提议」，不能「擅自做」**。但不同操作的安全级别不同，体验也不同：

```
记待办、记工时、生成日报（日常低风险）
   → 一步直达：你说一句，它直接办妥，不会反复问你
   
动你的文件、改环境、导入数据（高风险）
   → 先展示将做什么 → 你确认 → 才执行
```

### 两种确认情况

**1. 日常操作（记待办、记工时、生成日报等）**

**免确认，一句话直达**。比如你说「记个待办：明天交报销单」，AI 直接记录并回你「已记录 ✓」。不用等它问你。

**2. 文件/环境操作（动你的文件、查系统、导入备份）**

严格模式，**先展示影响清单，你确认后才执行**，AI 会提示「需要人工确认」。

如果你希望以后整理文件也不用每次都确认：

1. 用记事本打开 `D:\git-workspace\mcp-projects\e-worker-mcp\config.json`
2. 在 `"auto_approve"` 那行的方括号里加一项 `"file.*"`（注意前面要有逗号）
3. 保存，重启 AI 助手

改完之后长这样：

```json
{
  "safety": {
    "mode": "whitelist",
    "auto_approve": ["todo.*", "time.*", "report.*", "meeting.*", "file.*"],
    "allow_rules": ["todo.*", "meeting.*", "time.*", "report.*", "file.*"],
    "deny_rules": ["file.delete", "env.modify"]
  }
}
```

> 放心：就算放行了，文件操作也只会**移动文件**（清理是移到 `.trash` 回收文件夹），**永远不会真的删除你的文件**。

### 三种模式，选一个心理有数就行

| 模式 | 意思 |
|------|------|
| 白名单（默认） | 没在名单里的操作一律不许做，安全但偶尔要确认 |
| 黑名单 | 除了明确禁止的操作，其他都允许，省事但胆子大 |

默认白名单就好，不用改。日常记待办/工时/日报是免确认的，只有动文件才需要确认。

## 六、数据存在哪？怎么备份？

- 你的所有待办、工时数据存在这个文件里：`D:\git-workspace\mcp-projects\e-worker-mcp\db\e-worker.db`
- 换电脑 / 怕丢？跟 AI 说「备份一下数据」，它会导出成一个文件；到新电脑装好后再说「导入这个备份文件」。

## 七、常见问题

**Q：AI 说没有这个工具 / 找不到 e-worker**
A：MCP 配置没生效。检查命令路径是否和实际一致，保存后**完全退出并重开** AI 助手。

**Q：AI 让我确认一件事，我不想让它做**
A：直接说「不用了/取消」。确认前它什么都不会做。

**Q：文件整理被拦了，说需要人工确认**
A：见「五、安全是怎么回事」第 2 种情况，放行 `file.*` 即可。不放行也行，就是每次都要确认。

**Q：我删掉的文件去哪了？**
A：工具**不会删文件**。整理是移动，清理是移到 `.trash` 文件夹。真要删，自己手动删。

**Q：数据会不会上传？**
A：不会。数据只在你电脑的本地数据库里，没有服务器、不联网上传。
